## Running Locally
1. Clone this repo
2. Run `make` to install dependencies, build the database, and launch the dashboard
3. Open the local URL shown in your terminal to access the dashboard

## Project Structure
- `requirements.txt` - installs necessary dependencies
- `load_data.py` - Executes Parts 1 - 4
- `dashboard.py` - Streamlit app presenting tables and plots
- `Makefile` - automates the full pipeline
